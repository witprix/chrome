Folder → ZIP

Runs entirely in this page. No external scripts, no network requests, no other app. Pick a folder, it zips it in your browser's memory, then saves .zip file(s) to your Downloads folder.

Photos show real thumbnails. Video/audio/documents show a file icon — thumbnails aren't decoded for those to keep this light on mobile.

This page can only show and zip files — it has no permission to delete or edit anything in the original folder. To remove originals after your backup, use the Files app or WhatsApp's own Storage and data → Manage storage screen.

Tip: step 1, to reach WhatsApp's media, use the folder picker and navigate to Android → media → com.whatsapp → WhatsApp → Media. Recent Android versions restrict browser access to some app-private folders (Android/data); this page can only reach whatever the system picker allows you to select — that's an OS-level restriction, not a limitation of this script.
